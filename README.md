# Modul 09 PAW - Routing dan Bundling Asset di Laravel 13
Martin M.R. Simamora - S1 Sistem Informasi, Telkom University Surabaya

## Menjalankan
```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
npm install
npm run dev          # terminal 1
php artisan serve    # terminal 2
```
Halaman: `/routing` (praktik routing), `/webstatis` (portofolio, Tugas nomor 2).
